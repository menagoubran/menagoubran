# Quality Checklist & Validation System

## Pre-Publish Checklist

### Script Checks

- [ ] Hook appears in first 2 seconds
- [ ] Value delivered by 10 seconds
- [ ] 3 clear steps or principles included
- [ ] CTA is actionable
- [ ] No book titles, law numbers, or direct quotes
- [ ] No manipulation framing
- [ ] Second-person framing used throughout
- [ ] Total length: 28-35 seconds when read normally
- [ ] No sentence longer than 12 words
- [ ] One sentence per line format

### Visual Checks

- [ ] Every line has a Pexels keyword
- [ ] Keywords are vertical-video friendly
- [ ] No literal representations (no actual mirrors for "mirroring")
- [ ] Humans > abstract backgrounds
- [ ] High-contrast, readable text overlays specified
- [ ] Pattern interrupt planned at 5-7 seconds

### Caption Checks

- [ ] Two short lines maximum
- [ ] 2-4 emojis used (only: :eyes: :brain: :exploding_head: :warning:)
- [ ] Exactly 4 hashtags: #LaughHackDaily #FYP #ViralHack #ComedyHacks

### Compliance Checks

- [ ] Uses observation framing (not instruction)
- [ ] Focuses on self-improvement (not manipulation)
- [ ] Creates curiosity through recognition
- [ ] Ends with incomplete resolution
- [ ] No academic or instructional tone

## Performance Diagnostics

### Under 200 views after 2 hours

**Diagnosis:** Hook failed or first frame not scroll-stopping

**Fixes:**
1. Rewrite first 2 seconds with stronger curiosity gap
2. Add bolder text overlay in first frame
3. Ensure first visual is attention-grabbing
4. Test different hook patterns from bank

**Analysis Questions:**
- Was the hook too generic?
- Did the first frame blend into feed?
- Was the topic too niche?

---

### 200-1,000 views

**Diagnosis:** Hook okay, retention weak

**Fixes:**
1. Add pattern interrupt at 5-7 seconds
2. Strengthen loop line (make ending more incomplete)
3. Tighten pacing in middle section
4. Cut any repetitive content

**Analysis Questions:**
- Where did viewers drop off?
- Was the middle section engaging?
- Did the explanation drag?

---

### 1,000+ views

**Diagnosis:** Algorithm approved

**Action:** Turn into series immediately using Series Template

**Next Steps:**
1. Generate 5-part series
2. Post follow-up within 24 hours
3. Cross-reference in pinned comment
4. Track which episode performs best

## Content Validation Rubric

### Hook Quality (Score 1-10)

| Score | Criteria |
|-------|----------|
| 1-3 | Generic, doesn't create curiosity |
| 4-6 | Somewhat interesting, could be stronger |
| 7-8 | Strong curiosity gap, personal feel |
| 9-10 | Instant scroll-stop, must-watch |

### Value Delivery (Score 1-10)

| Score | Criteria |
|-------|----------|
| 1-3 | Vague, no actionable insight |
| 4-6 | Some value, but could be clearer |
| 7-8 | Clear steps, applicable insight |
| 9-10 | Immediately useful, memorable |

### Loop Potential (Score 1-10)

| Score | Criteria |
|-------|----------|
| 1-3 | Complete closure, no reason to rewatch |
| 4-6 | Somewhat open, might rewatch |
| 7-8 | Clearly incomplete, want to rewatch |
| 9-10 | Must rewatch to catch everything |

### Faceless Compatibility (Score 1-10)

| Score | Criteria |
|-------|----------|
| 1-3 | Requires specific visuals or face |
| 4-6 | Workable with stock footage |
| 7-8 | Natural fit for faceless format |
| 9-10 | Perfect for stock footage storytelling |

## Red Flags (Automatic Rejection)

Content must be rejected if any of these are present:

1. **Direct quotes** - Even paraphrased quotes over 10 words
2. **Author names** - Any mention of source authors
3. **Law numbers/chapters** - Any reference to original structure
4. **Manipulation framing** - "How to manipulate," "control others"
5. **Academic tone** - Sounds like a lecture or textbook
6. **Over 35 seconds** - Exceeds maximum length
7. **More than 4 hashtags** - Breaks hashtag rules
8. **Third-person framing** - Uses "they" instead of "you"
9. **Tutorial title hook** - Sounds like "How to..."
10. **Definitive closure** - Ends with complete resolution

|---------|------------|--------------|
