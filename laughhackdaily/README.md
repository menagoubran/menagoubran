# LaughHackDaily TikTok Automation System

Automated content production system for the faceless psychology TikTok channel "LaughHackDaily."

## Quick Start

```
new hack: [your topic]
```

## System Overview

This system transforms classical philosophy and psychology concepts into viral 30-second TikTok videos optimized for completion rate, rewatch rate, and algorithmic distribution.

### Core Principles

- **Duration:** 30 seconds (28-35 acceptable)
- **Framing:** Always self-improvement, never manipulation
- **Tone:** Observational, never academic
- **Source:** Classical philosophy + modern behavioral psychology

## The 4 Masks

Every video uses one of these framing approaches:

1. **OBSERVATION (50%)** - "Have you noticed how..."
2. **SELF-REFLECTION (30%)** - "If this keeps happening to you..."
3. **SOCIAL PATTERN (15%)** - "People tend to do this when..."
4. **WARNING (5%)** - "Be careful when..."

## Video Structure

```
0:00-0:02 → Hook (instant scroll-stop)
0:02-0:05 → Setup (introduce the pattern)
0:05-0:15 → Three steps/principles (core value)
0:15-0:25 → Explanation (why it works)
0:25-0:30 → CTA + Loop trigger
```

## Compliance Rules

### Always
- Observation framing
- Self-improvement focus
- Second-person ("you")
- Incomplete resolution ending

### Never
- Direct quotes from sources
- Author names
- Law numbers or chapters
- Manipulation framing
- Academic tone
- Over 35 seconds
- More than 4 hashtags
